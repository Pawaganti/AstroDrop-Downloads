# AstroDrop

在 Windows 和 Android 设备之间传输文件、文件夹和文字。连接同一局域网，完成配对后即可发送，无需注册账号。

## 功能

- **文件互传**：发送图片、视频、音频、文档、压缩包及其他文件，也可传输整个文件夹。
- **文字与剪贴板**：发送纯文本和链接，保留换行；Windows 支持粘贴图片。
- **局域网配对**：输入六位数字配对码连接设备，Android 支持扫码配对；已配对设备可重命名。
- **会话浏览**：查看传输状态、文件大小和进度；批量图片、视频以合集展示。
- **桌面投递**：支持拖放文件、快捷小窗、悬浮投递和托盘操作。
- **手机文件管理**：分类、搜索、排序、多选和文件预览。
- **文件夹自动发送**：Windows 可监听指定文件夹，将新增内容发送到选定设备；默认关闭。

## 开始使用

1. 电脑安装 Windows 版本，手机或平板安装安卓版本。
2. 将设备连接到允许相互访问的 Wi-Fi、热点或有线局域网。
3. 打开设备管理，一端显示配对码，另一端输入六位数字；也可用 Android 扫描配对二维码。
4. 选择接收设备，拖入文件或选择素材发送。

Windows 安装版与便携版使用相同程序。覆盖安装保留配置和配对记录；安卓更新请选择覆盖安装，不先卸载。

## 网络要求

文件通过局域网直接传输，不提供公网云中转。访客网络隔离、防火墙或禁止局域网访问的 VPN/TUN 可能影响设备发现与连接。
